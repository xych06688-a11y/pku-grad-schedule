# 研究生课表与作业管理 · Android 版

## 一、交付物

| 项目 | 内容 |
|---|---|
| 安装包 | `android/out/GradSchedule-v1.0.apk`（约 0.34 MB） |
| 应用名 | 研究生课表 |
| 包名 | `cn.edu.pku.schedule` |
| 版本 | 1.0（versionCode 1） |
| 最低系统 | Android 5.0（API 21）及以上 |
| 签名 | 已签名（SHA-1 `f3597b0d...`），非调试签名，可直接安装 |
| 架构 | 通用 dex，无需 NDK，arm / arm64 / x86 均可安装 |

## 二、安装步骤

1. 把 `GradSchedule-v1.0.apk` 传到手机（微信文件传输助手 / QQ / 数据线 / 蓝牙均可）。
2. 手机上点开该 APK。
3. 系统提示「未知来源应用」时，允许一次（不同品牌路径不同：设置 → 安全 → 安装未知应用）。
4. 安装完成后桌面出现蓝色课表图标「研究生课表」。

> 若手机提示「安装包异常/有风险」，属于自签名应用的常规拦截，选择「继续安装」即可。

## 三、功能

- **学期课表**：三时段网格（上午 08:30–11:30 / 下午 14:00–17:00 / 晚上 18:00–21:00），按周切换，周次不匹配的课自动灰显；未排课的课程单独列在「待定」区。
- **选课模式**：55 门课全量导入，自动识别时间冲突并归入同一格子（红色虚线框 + 冲突组编号）；同组互斥选择，实时统计学分。时间重叠但周次不相交的（如单周/双周班）单独列为「周次错开」，判定为**不冲突**。
- **作业管理**：记录提交方式、内容、教材/PPT 章节、截止时间，可按周查看、标记提交。
- **Excel 导入**：App 内「导入 Excel 课表」可直接选择手机上的 `.xlsx`，自动识别表头（课程名称/教师/学时/时间/星期列/备注），解析后先出预览，勾选「已选」即可写入课表。备注中的真实起止时间（如 `13:00-17:00`）、单双周、`9月15日开课` 都会被解析。
- **数据管理**：右下角「☰ 数据」可查看数据量、导出 JSON 备份、清除本地数据恢复内置示例。
- **本地存储**：数据存在 App 内（原生存储 + localStorage 双通道），完全离线，不联网、不上传。

## 四、与桌面原型的差异

- 网格支持横向滑动（7 列在窄屏放不下），弹窗改为底部抽屉式，按钮与文字按触控尺寸放大。
- 数据持久化到本机；首次启动即落盘，之后每次变更自动保存。
- 返回键：弹窗打开时先关弹窗，否则退出 App。
- 已内置 SheetJS，Excel 解析在手机上离线完成。

## 五、已知限制

1. **截图识别（OCR）未内置**：离线环境无法做中文 OCR。「截图识别变更」目前用作手动录入变更的入口，识别结果由人工填写确认。
2. **导出备份位置**：`Android/data/cn.edu.pku.schedule/files/Download/课表备份.json`（部分文件管理器需开启「显示隐藏/内部存储」才能看到）。
3. 导入新课表会覆盖当前课程数据，导入前建议先导出备份。

## 六、重新构建

```bash
node tools/build_apk.js
```

脚本会自动完成：生成移动端页面 → 生成图标 → aapt2 编译资源 → javac 编译 → d8 转 dex → 打包 → zipalign → 签名，输出到 `android/out/`。签名证书在 `android/signing.jks`（口令 `schedule2026`），后续升级请沿用同一证书，否则无法覆盖安装。
