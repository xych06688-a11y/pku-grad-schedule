## 0. 文档说明

### 0.1 目的

本文档用于界定「研究生课程表与作业管理系统」的功能范围、数据结构、字段定义与优先级，作为后续原型设计、开发实现与验收的依据。

### 0.2 范围界定

**本期范围（v1.0）**：课程表网格展示、Excel / 截图数据导入、作业与 DDL 管理、变更提醒、本地数据存储与导出。

**不在本期范围**：多人实时协同编辑、教务系统账号直连（需官方接口授权）、移动端原生 App、AI 自动写作业。

### 0.3 术语表

| 术语 | 定义 |
|---|---|
| 时段（Slot） | 一天的固定教学区间，本系统固定为上午 08:30–11:30、下午 14:00–17:00、晚上 18:00–21:00 |
| 周次（Week） | 学期内的教学周序号，从 1 开始；支持区间、单双周与不连续周 |
| 排课记录（ScheduleSlot） | 「某门课在某学期第 N 周的星期 X 的某个时段、在某教室上课」的最小条目 |
| 变更事件（ChangeEvent） | 教务发布的调课、停课、补课、换教室等通知，经解析后与原排课做差异比对 |
| DDL | 作业 / 任务的提交截止时间 |
| 负荷（Load） | 某一周内作业数量与预估工时的加权值，用于过载预警 |

## 1. 产品概述

### 1.1 问题陈述

研究生的课程安排与本科有本质差异，通用课程表工具普遍失效，具体痛点如下：

1. **周次不连续**：一门课可能只上第 1–8 周（前半学期课），或隔周上（单双周），本科课表工具普遍假设「全学期每周都有」。
2. **变更频繁且滞后**：教室规划与调停课通知常以截图 / PDF 形式发在群聊里，学生需手工比对原课表，极易漏看。
3. **时段不规整**：研究生课程常为 3 小时连排（8:30–11:30），且大量课程排在晚上，通用工具的「小节制」不适用。
4. **作业形态多样**：不是「做题」而是「读论文 + 写报告 + 代码复现 + 课堂展示」，且需关联教材 / PPT 的具体章节页码。
5. **DDL 跨课程堆叠**：多门课的截止日期集中在同一周，缺少统一视图与提前量提醒。
6. **上课与科研交织**：组会、学术报告、导师会面、资格考试同样占用时间，但不出现在教务课表中。

### 1.2 目标用户画像

| 画像 | 特征 | 核心诉求 |
|---|---|---|
| 研一授课型硕士 | 课程密集，兼顾组会 | 别漏课、别漏作业、别走错教室 |
| 直博 / 硕博连读生 | 课程少但科研任务重 | 资格考试、文献阅读、组会的统一管理 |
| 在职研究生 | 晚上 / 周末上课 | 移动端今日视图、行程提醒 |
| 助教（TA） | 需协助教师发布作业与批改 | 作业批量导入、成绩记录 |

### 1.3 核心场景（User Story）

| 编号 | 场景 | 描述 |
|---|---|---|
| US-1 | 一键建表 | 作为研一新生，我导入教务导出的 Excel 课表，系统自动填充到三时段网格，10 秒内看到完整学期课表 |
| US-2 | 截图识别变更 | 班长在群里发了「第 3 周教室调整通知」截图，我拖入系统，系统自动比对出「机器学习理论：主楼 B105 → B203」，我确认后课表更新 |
| US-3 | 每周作业导入 | 每周日晚，我把本周各科新作业录入（或用模板批量导入），系统按课程归入对应格子并显示角标 |
| US-4 | DDL 预警 | 作为学生，我在截止前 24 小时收到提醒，且能看到本周所有 DDL 的时间轴，避免撞车 |
| US-5 | 过期课程自动隐藏 | 第 9 周时，只上 1–8 周的课自动从网格淡出，不再干扰视线 |
| US-6 | 学习回溯 | 期末时，我导出本学期的课程 + 作业 + 成绩统计，作为学业总结材料 |
| US-7 | 选课排雷 | 选课期，我导入含 40 门候选课的全校清单，系统自动把时间冲突的课聚到同一个格子里标红，我一眼看出哪几门互斥，选完直接生成正式课表 |
| US-8 | 周次错开识别 | 两门课都是周一上午，但一个 1–8 周、一个 9–16 周，系统明确告诉我这两门不冲突、可以都选 |

### 1.4 产品定位

**「为研究生设计的、能读懂教务通知的课程与任务中枢」**——不是又一个日历 App，而是围绕「课程表 + 作业 + 变更」三件事做深的专用工具。

## 3. 功能需求

> 编号规则：`FR-<模块>.<序号>`。优先级标记：`P0` 必须有 / `P1` 应该有 / `P2` 可以有 / `P3` 远期探索。

### FR-1 课程表（P0）

#### FR-1.1 周视图网格（P0）

- 以 **7 列（周一至周日）× 3 行（上午 / 下午 / 晚上）** 的网格呈现，行首标注时段与固定时间范围。
- 网格形态与常规课程表一致：列头为星期 + 日期（如「周一 09-07」），行头为时段。
- 每个单元格内可容纳 **多门课程**（同一时段可能存在并行选修课或冲突），以课程卡片堆叠展示。
- 当前日期所在列高亮；当前时段所在单元格边框加粗。
- 支持在「周一至周日」与「周一至周五 + 周末折叠」之间切换显示。

#### FR-1.2 周次引擎（P0）

- 顶部提供周次选择器（第 1 周 … 第 N 周），并支持 `←/→` 快捷键与「回到本周」按钮。
- 依据学期起始日期自动计算「今天是第几周」，打开应用默认定位到当前周。
- 排课记录支持周次表达式：`1-16`、`1-8,10-16`、`单周`、`双周`、`1,3,5,7`。
- **过期周次的课程自动淡出**（仍可切换回去查看），已结束课程不占视觉焦点。
- 支持节假日 / 调休：维护「特殊日期表」，标记某天按周 X 的课表执行（补课日）。

#### FR-1.3 课程卡片信息（P0）

卡片默认展示四行：**课程名称 / 教师 / 教室 / 周次标签**；角标展示：

| 角标 | 含义 | 样式 |
|---|---|---|
| 作业数 | 该课程本周未提交作业数 | 右上红色圆点数字 |
| 变更 | 存在待确认的调课 / 换教室 | 橙色三角警示 |
| 线上 | 授课形式为线上 / 混合 | 蓝色链接图标 |
| 状态 | 已停课 / 已补课 | 灰色删除线 + 说明 |

#### FR-1.4 单元格交互（P0）

- 单击卡片：展开侧边抽屉，显示课程详情 + 该课程本周作业列表 + 教材章节。
- 双击空白单元格：快速新增排课 / 非课程事件（组会、报告）。
- 右键菜单：编辑、复制、删除、添加作业、标记停课、查看变更历史。
- 拖拽：支持将课程卡片拖到另一单元格完成调课（拖拽后自动生成一条手工变更记录）。

#### FR-1.5 今日视图（P1）

- 移动端 / 窄屏下的单列视图：今天的三个时段 + 今天到期的作业 + 明天的预习提示。
- 桌面端提供「今日」快捷入口与桌面小组件（可选）。

#### FR-1.6 打印与图片导出（P1）

- 一键导出当前周课程表为 PNG / PDF（A4 横版），可设为壁纸或打印张贴。
- 支持隐藏作业角标等隐私信息的「纯净模式」。

### FR-2 数据导入（P0）

#### FR-2.1 Excel 课程表导入（P0）

- 支持 `.xlsx` / `.xls` / `.csv`，多工作表时让用户选择目标 Sheet。
- **自动识别表头**：内置别名映射表（见附录 A），模糊匹配列名，识别率不足时进入「手动指定列」模式。
- **时间 → 时段归一化**：按规则表（见 §5.1）把 `08:30-11:30` 之类的时间区间映射到三时段之一；无法唯一映射的标记为「待人工确认」。
- **周次表达式解析**：支持 `1-16周`、`1-16`、`第1-16周`、`1,2,3`、`单`、`双`。
- **星期归一化**：`星期一 / 周一 / Mon / 1` 统一为 1–7。
- **教室拆分**：`逸夫楼A302` 尝试拆分为「教学楼 + 房间号」，失败则整体存入地点字段。
- 解析后进入 **预览页**：以网格形式高亮「将写入的格子」，列出异常行（缺课程名 / 时段无法识别 / 时间冲突），用户勾选后确认导入。
- 导入模式：`追加`、`覆盖本周`、`全量替换（按学期）`。

#### FR-2.2 教务截图 / PDF 识别（P1，核心差异化）

适用三类截图：**① 教室规划表 ② 调课停课通知 ③ 考试安排表**。

处理流水线：

1. **预处理**：纠偏、去噪、增强对比度、超分（低清截图）。
2. **版面分析**：检测表格线，投影切分为行列；无表格线的走文本块聚类。
3. **OCR**：本地 OCR 引擎输出文本 + 坐标 + 置信度。
4. **字段抽取**：关键词词典 + 正则（见附录 B），抽取课程名、教师、原时间地点、新时间地点、生效周次、原因、发布单位、发布日期。
5. **归一化**：复用 §5.1 的时段映射与周次解析。
6. **差异比对**：与现有排课记录匹配（课程名相似度 + 教师 + 星期时段），生成 `原值 → 新值` 的 diff。
7. **人工确认**：`原值 → 新值` 对照表，置信度 < 0.8 的条目默认折叠并高亮，用户逐条确认 / 编辑 / 忽略。
8. **应用与留痕**：确认后写入 ChangeEvent 并更新排课，原始截图与 OCR 原文一并存档，可回溯。

- 支持一次拖入多张截图，批量排队处理。
- 支持导出识别结果为结构化 JSON，便于纠错后重导。

#### FR-2.3 文本 / 粘贴导入（P1）

- 支持直接粘贴 Excel 区域、Markdown 表格、教务网页文本，走与 Excel 相同的解析管线。
- 支持自然语言快速录入：`周三上午 机器学习 主楼B105 1-16周`。

#### FR-2.4 导入日志与回滚（P1）

- 每次导入生成 `ImportBatch`，记录来源文件、解析规则版本、成功 / 失败条数、原始文件快照。
- 支持按批次「撤销导入」，回滚到导入前状态。

### FR-3 作业管理（P0）

#### FR-3.1 作业录入（P0）

- 支持从「课程卡片 → 添加作业」与「全局 + 新建作业」两个入口录入。
- 必填字段：课程、标题、截止时间；其余可空（详见 §4.6 字段定义）。
- 支持附件：教师发的 PDF、模板 docx、数据集链接。

#### FR-3.2 作业与课程 / 课时绑定（P0）

- 每条作业必须归属一门课程；可选绑定到「第 N 周 / 某一次课」，便于回溯「这次课上布置了什么」。
- 支持关联教材章节：从该课程的资料库中选择「教材名 + 第 X 章 / PPT 第 X–Y 页」，点击可直达本地文件并定位。

#### FR-3.3 作业看板（P0）

- 四列看板：`未开始 / 进行中 / 已提交 / 已批改`，支持拖拽流转。
- 与本周一格联动：课程格子上显示本周未提交数角标。
- 排序：按截止时间升序；提供「按课程」「按紧急度」「按预估工时」分组视图。
- 过滤器：课程、状态、时间范围（本周 / 本月 / 全部 / 已逾期）。

#### FR-3.4 提醒（P1）

- 默认提醒策略：截止前 `7 天 / 3 天 / 1 天 / 3 小时`，可逐条自定义。
- 提醒渠道：应用内通知 → 系统通知 → 可选邮件 / 微信（需用户配置）。
- 每日「晨报」：今天有什么课、今天 / 明天要交什么。
- 「今晚必做」清单：按剩余时间与工时，自动排出今晚可完成的作业组合。

#### FR-3.5 作业模板与批量导入（P1）

- 支持为课程定义作业模板（如「每周文献阅读报告：提交方式=学习平台，章节=本周论文，截止=下周二 23:59」），一键生成整学期重复作业。
- 支持从 Excel / CSV 批量导入作业清单（周末集中录入场景）。
- 支持复制上一周作业为模板。

#### FR-3.6 作业详情与附件（P1）

- 详情页展示：描述、提交方式 + 提交地址（可点击跳转）、教材章节、附件列表、完成进度、提交时间、成绩与教师反馈。
- 支持记录「实际耗时」，用于后续工时估算校准。

### FR-4 教材与资料库（P2）

- 每门课程关联教材 / 参考书 / PPT / 论文列表，支持章节（Chapter）粒度。
- 章节可被打钩「已读」，作业关联的章节自动高亮。
- 支持本地文件路径 / 网盘链接 / DOI，点击调用系统默认程序打开。

### FR-5 变更中心（P1）

- 统一收口所有调课、停课、补课、换教室、改线上等变更。
- 列表展示：`课程 · 生效周次 · 变更类型 · 原值 → 新值 · 来源 · 状态`。
- 状态流转：`待确认 → 已应用 / 已忽略 / 已过期`。
- 变更应用到课表后，在原格子上保留「变更」标记，鼠标悬停显示变更说明。
- 支持回滚单条变更。

### FR-6 DDL 日历与时间轴（P1）

- 月视图日历：按截止日铺点，颜色区分课程，逾期项标红。
- 周时间轴（甘特）：横轴为日期，显示每门作业的「发布 → 截止」区间，直观暴露 DDL 撞车。
- 支持导出 `.ics`，订阅到系统日历 / 手机日历。

### FR-7 统计（P2）

| 指标 | 说明 |
|---|---|
| 周负荷热力图 | 每学期的作业数量 / 预估工时热力分布，识别最忙的几周 |
| 课程负荷占比 | 各门课布置的作业数与工时占比 |
| 完成率 | 按时提交 / 逾期提交 / 未提交 |
| 学分进度 | 已修 / 在读 / 待修学分，对照培养方案要求 |
| 成绩 | 录入后计算 GPA、学分绩，展示分布 |

### FR-8 数据管理（P1）

- 本地数据库 + 附件目录的整体备份 / 恢复（`.zip` 快照）。
- 导出：Excel 课表、CSV 作业清单、JSON 全量数据、ICS 日历、PNG / PDF 课程表图片。
- 自动备份：每日首次启动时快照，保留最近 7 份。
- 可选云同步（v1.1）：WebDAV / 网盘目录同步，端到端不上传明文。

### FR-10 选课模式（选课沙盘）（P0-选课期）

> 定位：与 FR-1 的「已定课表」并列的第二种工作模式。选课期使用全量课程清单做冲突排查，选课后一键沉淀为正式课表（FR-1）。

#### FR-10.1 全量课程清单导入（P0）

- 输入：仅含**课程名 + 上课时间**的最小清单即可（其余字段可空），支持 Excel / CSV / 直接粘贴。
- 一门课可含**多个上课时间**（如「周一 08:30–11:30；周三 14:00–17:00」），解析为多条候选项。
- 时间写法兼容：`周一 08:30-11:30`、`星期一 上午`、`Mon 8:30~11:30`；缺省具体时间时按三时段默认区间补全。
- 周次写法兼容：`1-16周`、`9-16`、`单周`、`双周`；缺省按全学期。
- 解析后展示「解析预览」，列出未识别行供手工修正。

#### FR-10.2 冲突识别与同格聚合（P0，核心）

- **冲突判定**：两门课**同一天的时间区间相交**，**并且**周次存在交集 → 判为冲突（算法见 §5.7）。
- **同格聚合**：冲突的课程全部渲染进同一个时间格子里，外层以红色虚线框包裹，标题显示「时间冲突 ×N」与冲突组编号（G1、G2…）；**不冲突的课程按普通卡片单独渲染**，视觉上一眼可分辨。
- 冲突组内成员互为**互斥**：选中其一，同组其余自动置为「排除」并灰显加删除线。
- 支持多人（≥3 门）冲突：如 A 与 B 冲突、B 与 C 冲突，则 A/B/C 归入同一冲突组（并查集连通分量）。

#### FR-10.3 选课态与学分统计（P1）

- 每门课三态：`候选 / 已选 / 排除`，点击卡片可切换；网格与冲突组列表同步更新。
- 侧栏实时统计：清单总数、已选门数与学分、候选待定、已排除、冲突组数量。
- 支持设置**学分上限**（如最低 24 / 最高 32），超限高亮提示。

#### FR-10.4 冲突组清单（P1）

- 侧栏以「冲突组卡片」列出每组：冲突时间窗（`周一 08:30–11:30`）、周次交集、互斥成员（点击可跳转/选中）。
- 「已选」成员高亮，「排除」成员灰显删除线。
- 单独列出**「周次错开（不算冲突）」**清单：时间重叠但周次不相交的课程对，明确告知用户这两门可以同时选，避免误判。

#### FR-10.5 方案沉淀与导出（P1）

- 校验通过后一键「导出为正式课表」：将「已选」课程写入 Course / ScheduleSlot，进入 FR-1 学期课表模式。
- 存在未解决冲突（同一组内两门均「已选」）时阻止导出并定位冲突。
- 支持保存多个选课方案（方案 A / B）并对比学分与冲突数。

**界面要点**：选课模式的网格无周次切换（全学期叠加），单元格高度自适应、内部可滚动；冲突组框用**红色虚线 + 浅红底**，普通候选卡片用**灰边框 + 左侧色条**，已选卡片用**主题色实线 + 浅蓝底**。

### FR-13 考勤方式（P1）

- 每门课程可填写**考勤方式**，**可选项**：不填则该字段不参与任何展示与校验。
- 取值建议（下拉 + 可留空）：课堂点名 / 扫码·刷码签到 / 随堂小测 / 作业代考勤 / 线上签到 / 签退 / 无需考勤 / 其他。
- 填写后：课程详情与**课表卡片**上追加「考勤 xxx」标记，用于上课前自我提醒。
- 该字段在选课阶段即可填写，并随「导出为正式课表」带入 Course，避免二次录入。
- 与 FR-5 变更中心联动设想（P2）：调停课影响到考勤方式时（如线下改线上）提示更新。

### FR-14 每日学习计划（P1）

**定位**：课表回答「我在哪上课」，学习计划回答「我在哪个时段学什么」。二者共用同一套三时段网格，但学习计划以**周**为粒度独立编辑。

- **按格子安排**：每个「星期 × 时段」格子可添加多条计划，字段：内容、关联课程（可空）、预计时长、备注、完成状态。
- **自动感知周次**（关键）：格子内先渲染本周该时段的课程，判定同 FR-1，即 `slot.weeks.includes(W)`——**单周课只在奇数周出现、双周课只在偶数周出现**；本周不上的课以灰显「本周不上」标注，不占用视觉重点。
- **两种典型场景**：
  - **没课的时段学**：格子内无课，直接添加计划，卡片为主题色。
  - **上课时学别的**：格子内有课仍可添加计划，弹窗给出提醒并默认勾选「上课时学别的」，保存后卡片**标黄**（`clash=true`），侧栏「上课时学别的」清单集中汇总，避免用户误以为该时段空闲。
- **与作业打通**：添加计划时可从「本周待办作业」下拉带入，自动填充标题与关联课程，并按预估工时预选时长。
- **周维度操作**：复制上周计划（重置完成态）、清空本周计划。计划按 `week` 存储，故每周可不同，天然支持单双周节奏。
- **侧栏统计**：计划条目 / 已完成 / 未完成预计工时 / 上课时学别的条数 / **空闲时段**（本周既无课也无计划的格子）。

### FR-3 补充：作业待办清单（P1）

- 每条作业可拆分为**子任务清单**（todo），每条含文本与完成态，支持勾选、追加、删除。
- 作业列表与作业详情显示 `已完成 / 总数` 进度；全部完成时提示「可以标记为已提交了」。
- 新建作业时支持「每行一条」批量录入子任务。
- 待办清单与 FR-14 学习计划解耦：清单描述**做什么**，计划描述**什么时候做**。

### FR-9 设置（P1）

- 学期管理（新建 / 切换 / 复制上学期课程）。
- 时段自定义（默认三时段，允许学校差异时微调起止时间）。
- 提醒策略、主题（浅色 / 深色）、语言、课程配色方案。
- 导入规则自定义（字段别名可编辑，保存为「我的学校模板」）。

## 4. 数据模型与字段定义

### 4.1 实体关系概览

```
Semester 1──n Course 1──n ScheduleSlot
                    ├──n Assignment  n──1 MaterialChapter
                    ├──n Material   1──n MaterialChapter
                    └──n Exam
Semester 1──n Event（组会/报告/考试等非课程事件）
ScheduleSlot 1──n ChangeEvent
Assignment 1──n Reminder
ImportBatch 1──n ImportItem / Attachment
```

### 4.2 学期 Semester

| 字段 | 类型 | 必填 | 取值 / 说明 |
|---|---|---|---|
| semester_id | UUID | 是 | 主键 |
| academic_year | string | 是 | 如 `2026-2027` |
| term | enum | 是 | `秋季 / 春季 / 夏季短学期` |
| start_date | date | 是 | 第 1 周周一的日期 |
| total_weeks | int | 是 | 默认 18 |
| current_week_override | int | 否 | 手工锁定当前周 |
| holidays | JSON | 否 | 特殊日期表：`{date, type: 放假/补课, 按周X执行}` |
| status | enum | 是 | `草稿 / 进行中 / 已结束` |

|---|---|---|---|

| hours | int | 否 | 学时 |

### 4.7 教材与章节 Material / MaterialChapter

| 字段 | 类型 | 必填 | 说明 |

| material_id | UUID | 是 | 主键 |

## 5. 关键业务规则与算法

### 5.1 时间 → 时段映射规则

三时段为 **固定值、非可配置默认值**（允许在设置中微调，但网格结构不变）：

| 时段 | 默认区间 | 判定规则（取课程起始时间 T） |
|---|---|---|
| 上午 morning | 08:30–11:30 | `T < 12:00` |
| 下午 afternoon | 14:00–17:00 | `12:00 ≤ T < 17:30` |
| 晚上 evening | 18:00–21:00 | `T ≥ 17:30` |

边界处理：

- **跨时段课程**（如 `08:30–12:00`）：按起始时间归位，并在卡片上标注「实际下课 12:00」，同时进入待确认列表。
- **跨中午 / 傍晚**（如 `13:30–16:30`）：归为下午，标注实际起止。
- **无法识别**：进入「未归类」抽屉，用户拖入目标格子完成分配。
- 若 Excel 提供「节次」（如 `1-3 节`）而非时间：按学校节次时间表换算；未知节次表时提示用户配置（默认 1–4 节 = 上午，5–8 节 = 下午，9–11 节 = 晚上）。

### 5.2 周次表达式解析

支持输入形态与归一化结果：

| 输入 | 解析结果 |
|---|---|
| `1-16周` / `1-16` / `第1-16周` | `[1..16]` |
| `1-8,10-16` | `[1..8, 10..16]` |
| `单周` / `单` / `odd` | `[1,3,5,...]`，parity=odd |
| `双周` / `双` / `even` | `[2,4,6,...]`，parity=even |
| `1,3,5,7` | `[1,3,5,7]` |
| 空 | 默认全学期 |

### 5.3 冲突检测

| 类型 | 规则 | 处理 |
|---|---|---|
| 时间冲突 | 同一周次同一时段存在两门课的排课记录 | 网格内并排显示并标红，提示用户确认是否为并行选修 |
| 教室冲突 | 同一周次同一时段同一教室被两门课占用 | 标记为「数据异常」，提示核对 |
| DDL 冲突 | 24 小时内有 ≥ 2 个 DDL，或单周预估工时 > 阈值（默认 20h） | 日历视图红色预警，晨报提示 |
| 变更冲突 | 变更生效周次内该格子已被其他变更占用 | 变更中心标黄，需人工裁决 |
| 过期未处理 | 变更发布日期 > 7 天仍为「待确认」 | 首页置顶提醒 |
| **选课冲突** | 同一天时间区间相交 **且** 周次有交集 | 归为同一冲突组，聚合进同一格子（见 §5.7） |
| **周次错开** | 时间区间相交但周次无交集（如 `1-8周` vs `9-16周`） | **不判为冲突**，单独列入「周次错开」清单并提示可同时选 |
| **跨时段会话** | 单次上课跨越两个固定时段（如 `10:00–13:00`） | 在两个时段格子中同时出现，按实际区间参与冲突判定 |
| **时段失配** | 上课时间不与任何固定时段相交（如 `12:00–13:00`） | 进入「未归类」抽屉，用户手工拖入或调整时段定义 |
| **学分超限** | 已选学分 > 上限 或 < 下限 | 统计面板红色高亮，导出前阻断 |

### 5.4 提醒策略

- 全局默认：`T-7d、T-3d、T-1d、T-3h`，晚上 22:00 后不推送（可配置免打扰时段）。
- 作业级可覆盖：`reminder_rule = ["7d","1d","2h"]`。
- 「今晚必做」算法：取 `due_at` 在未来 48 小时内且状态未提交的作业，按 `紧急度` 降序，累计 `estimated_hours` 不超过用户设置的「每晚可投入工时」，输出清单。

### 5.5 优先级自动计算

```
紧急度 U = 剩余时间得分 × 0.5 + 权重(weight) × 0.2 + 难度 × 0.1 + 预估工时 × 0.2
剩余时间得分：>7天=1，3-7天=2，1-3天=3，<1天=4，已逾期=5
priority：U ≥ 4.0 紧急；3.0–4.0 高；2.0–3.0 中；< 2.0 低
```

用户可手动覆盖自动结果，手动值优先。

### 5.6 置信度与人工确认策略

| 置信度 | 处理 |
|---|---|
| ≥ 0.90 | 自动应用，仅在变更中心留痕并弹出轻量提示 |
| 0.80–0.90 | 默认勾选，用户在预览页确认后应用 |
| < 0.80 | 默认不勾选并高亮，必须人工编辑或显式确认 |
| 关键字段（课程名、时间、教室）任一缺失 | 强制人工介入，不允许自动应用 |

### 5.7 选课冲突判定算法（FR-10）

**输入**：候选课程集合 `C`，每门课含若干「会话」`session = (day, start, end, weeks[])`。
**输出**：冲突组集合 `G`（每组 ≥2 门互斥课程）+ 周次错开对集合 `N`。

```
1. 展平：把所有 (课程, 会话) 对作为节点，记为 S
2. 并查集初始化：parent[s] = s
3. 对任意两个会话 a, b（同一节点内、同一课程内的两两比较跳过）：
     if  a.day == b.day
     and max(a.start, b.start) < min(a.end, b.end)        // 时间区间相交
     and a.weeks ∩ b.weeks ≠ ∅ :                          // 周次有交集
         union(a, b)                                       // 判为冲突
     else if 时间相交 但 周次无交集:
         N ← N ∪ {(a, b)}                                  // 周次错开，不冲突
4. 按根节点聚类：连通分量 size ≥ 2 的即为一个冲突组 G
5. 渲染：同一格子内，属于同一 G 的会话聚合进红色虚线框；其余单独渲染
6. 互斥：选中组内某门课时，同组其余课程自动置为「排除」
```

**设计说明**

| 要点 | 说明 |
|---|---|
| 为什么用区间而非时段 | 研究生常见 `09:00–11:00` 与 `10:00–12:00` 这类部分重叠；只比较「是否同一时段」会漏判部分重叠，只比较起止时间又过于严格。区间相交是唯一正确解 |
| 为什么必须叠加周次条件 | 时间完全相同但周次不重叠（前半学期 / 后半学期课程）是研究生高频场景，仅按时间判定会产生大量假冲突，严重干扰选课 |
| 为什么用并查集 | 支持传递冲突（A×B、B×C ⇒ A/B/C 同组），避免两两分组导致的「选了 A 又选了 C」漏洞 |
| 同课程多会话 | 同一门课的两个会话之间不做冲突比较，防止自身误判 |
| 复杂度 | O(n²) 会话两两比较，n ≤ 数百时可忽略；n > 1000 时按 (day, 时段) 分桶后比较 |

**冲突组展示信息**：组号 `G1`、冲突时间窗（取成员区间的最大覆盖 `min(start)`–`max(end)`）、周次交集、互斥成员列表。

## 附录 E：真实样本实测（北大软微 26-27 学年排课表）

> 来源：`1-1课表-电子信息和MEM（26-27学年度课表）0825.xlsx`，2026-09-13 实测。用于校准附录 A/B，并锁定 v1.0 解析器行为。

### E.1 文件结构

| 项 | 实测结果 |
|---|---|
| 工作表 | 4 个：`电子信息秋季`、`电子信息春季`、`25级MEM`、`26级MEM`（按「学年 + 学期 + 项目」分表） |
| 表头 | **双行表头**（第 3–4 行），第 1–2 行为标题，第 5 行起为数据 |
| 列结构 | A 课程编号 / B 课程名称 / C 主讲教师 / D 学时 / E **时间**（上午·下午·晚上·上午+下午·空） / **F–L 周一至周日**（网格式排课）/ M 教务员 / N 备注 |
| 单元格格式 | `班次编号/教室`，如 `4330-1班/3204`、`5348-1班/报告厅`；多教室换行 `0042/3204、\n报告厅` |
| 时段定义 | 表尾注明：**上午 8:30–11:30、下午 14:00–17:00、晚上 18:00–21:00** —— 与本系统三时段设定完全一致 |
| 学期范围 | 秋季 2026.9.7–2027.1.10，共 18 周（与 `SEM_START` / `TOTAL_WEEKS` 默认值一致） |

### E.2 关键解析发现（直接影响解析器设计）

1. **「时间」列只有时段，没有具体起止**；真实起止藏在**备注**里（`13：00-17：00`、`18:00-22:00`）。**必须把备注纳入解析**，否则中国式现代化（13:00 上课）与自然辩证法（1 班 13:00、2 班 18:00）的时间会算错。
2. **周次信息也在备注里**：`单周`、`双周`、`第1-6周`、`第7、8、9、10周周五下午`。解析器需从备注抽取周次表达式，缺省 1-18 周。
3. **同一门课多行 = 多个班**，行级去重不可行，必须保留「课程 + 班次」粒度（如算法分析与设计 01/02/03 班）。
4. **同名课程不同班可能周次互补**：中国式现代化 1 班单周、2 班双周 → 时间相同但**周次不相交 → 不是冲突**。这正是 §5.7 周次交集规则的真实依据。
5. **部分课程不排时间**：综合实践（4 个班）、学科专著研读、科研实践 I/II —— E 列为空且无日期单元格 → 归入「待定 / 不排课」。
6. **学分缺失**：该表只有「学时」，需按 `学分 = 学时 / 16` 折算（MEM 表才有学分列）。
7. **教室需归一化**：`3204 / 报告厅` 与 `3204、\n报告厅` 应视为同一值，比较前统一分隔符与空白。

2. 在表头行及其后 2 行内寻找含 ≥3 个「周X」的**星期行**，确定「星期 → 列」映射；
3. 列映射：课程名称 / 教师 / 学时 / 时段 / 备注 / 编号（关键词匹配，容错别名）；
4. 逐行生成排课：星期列非空即排课，教室取 `/` 后段；
5. 备注挖掘：真实起止时间 `\d{1,2}:\d{2}-\d{1,2}:\d{2}`、单周/双周、`X月X日开课 → 折算起始周`、`第a-b周`；
6. 过滤脏行（时段定义行、合计行、纯数字行、超长说明行）。

### F.5 构建链（无 Gradle / 无 Android Studio）

受环境限制（无 Gradle、JDK 8），采用 SDK 工具直连构建，见 `tools/build_apk.js`：

```
aapt2 compile(res) → aapt2 link(+assets, -A) → javac(-bootclasspath android.jar)
→ d8(dex) → aapt add(classes.dex) → zipalign -f 4 → apksigner sign
```

踩坑记录：
- **apksigner 与 JDK 版本**：build-tools ≥ 29 的 apksigner 需 Java 9+，JDK 8 报 `UnsupportedClassVersionError`。改用 build-tools **r28** 的 apksigner（Java 8 可用）。
- **assets 必须显式声明**：`aapt2 link` 需 `-A <assets目录>`，否则资产不进包（曾产出 20 KB 空壳 APK）。
- **dex 需手动加入**：`aapt add` 在 dex 所在目录执行。

### F.6 已知限制

1. 离线环境下中文 OCR 不可用，「截图识别变更」作为手动录入入口（见 §5.5 流水线的前置步骤仍有效，识别环节人工完成）。
2. 导出备份落在应用私有目录 `Android/data/cn.edu.pku.schedule/files/Download/`。
3. 导入新课表会覆盖当前课程数据（作业按课程 id 存活校验，失效项会被移除并提示数量）。

## 附录 H：考勤方式 / 学习计划 / 作业待办（v1.5）

### H.1 新增与变更字段

| 实体 | 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| Course | `attendance` | enum / string | **否** | 考勤方式。取值：课堂点名 / 扫码·刷码签到 / 随堂小测 / 作业代考勤 / 线上签到 / 签退 / 无需考勤 / 其他；空值 = 未填写 |
| Assignment | `todos` | `Array<{t:string, done:boolean}>` | 否 | 作业子任务清单；为空表示未拆分 |
| StudyPlan（新） | `id` | string | 是 | 主键 |
| StudyPlan | `week` | int(1..18) | 是 | 所属周次，计划按周独立存储 |
| StudyPlan | `d` | int(0..6) | 是 | 周一=0 … 周日=6 |
| StudyPlan | `p` | enum | 是 | morning / afternoon / evening |
| StudyPlan | `cid` | ref(Course) | 否 | 关联课程，可为空 |
| StudyPlan | `title` | string | 是 | 要做什么 |
| StudyPlan | `minutes` | int | 否 | 预计时长（分钟） |
| StudyPlan | `note` | string | 否 | 备注 |
| StudyPlan | `done` | boolean | 是 | 完成态，点击卡片切换 |
| StudyPlan | `clash` | boolean | 是 | 「上课时学别的」标记：该时段本周有课仍安排了其他学习 |

### H.2 单双周处理（关键规则）

学习计划格子在渲染前先按 `slot.weeks.includes(W)` 判定本周是否有课，**与 FR-1 学期课表共用同一套周次引擎**，因此：

- 单周课（如中国式现代化 1 班）在第 1、3、5… 周显示为「有课」，第 2、4… 周显示为灰显「本周不上」；
- 双周课反之；
- 计划条目按 `week` 存储，故第 2 周可在同一格子安排完全不同的内容，不受上周影响。

实测验证（jsdom）：只选一门单周课后导出，第 1 周 `classesAt = 1`、第 2 周 `= 0`、第 3 周 `= 1`，第 2 周网格出现「本周不上」标注。

### H.3 「上课时学别的」的判定

添加计划时若该格子本周有课，弹窗顶部给出橙色提醒，并**默认勾选**「上课时学别的」。保存后 `clash=true`，卡片标黄并在侧栏汇总。用户可手动取消勾选（例如把课上的内容当作该时段的学习安排，此时不算冲突）。

### H.4 导出流程修正（v1.5）

v1.4 及之前「导出为正式课表」仅提示成功，未写入数据。v1.5 起真正执行：

```
校验冲突 → 清空 courses / slots → 逐门「已选」课程写 Course（含 attendance）
        → times 按 periodsOf(t) 展开为 ScheduleSlot（跨时段课程生成多条）
        → 切换至学期课表模式
```

未排时间的课程（如综合实践各班）不会生成 slot，落入「待定 / 未排课」区。

## 附录 I：移动端纵向视图与去除周末（v1.6）

### I.1 问题
手机窄屏下，周×时段网格（6 列：时间 + 周一~周五）无法完整显示，必须横向滑动才能看全，课程名被截断。

### I.2 方案：窄屏切换为「按天分组的长条列表」
- 触发条件：`matchMedia('(max-width:900px)').matches`；窗口尺寸变化（resize）时自动重排。
- 结构：`.agd`（一天）→ `.agp`（一个时段）→ `.agrow`（一条课程长条），全部 `width:100%`、`min-width:0`，
  无 `min-width` 硬约束，因此**只会上下滚动，不会横向滚动**。
- 长条展示：课程名（可换行，不截断）+ 时间 / 教师 / 教室 / 周次 / 考勤；
  作业待办数显示为角标，存在未确认变更时显示「变更」「教室?」标记。
- 三种模式共用同一套骨架：
  - 学期课表：无课时段显示浅灰「无课」；本周不上的课灰显并注明「本周不上」。
  - 选课模式：每格一个 100% 宽下拉（含「— 无课 —」），已选课程以绿色长条回显。
  - 学习计划：课程提示 + 计划条目 + 「+ 添加计划」，与宽屏行为一致。
- 全局约束：`html, body { overflow-x: hidden }`，并移除旧的 `.gridwrap{overflow-x:auto}` 与
  `table.grid{min-width:640px}`，从根上杜绝横向滚动。

### I.3 去除周末（FR-16）
- 常量 `NDAY = 5`：课表列只渲染周一至周五（学期课表 / 学习计划 / 选课模式一致）。
- 周末不丢数据：`WEEKEND = [5,6]` 的课程由 `renderWeekend()` 渲染为兜底区块：
  - 学期课表：「周末排课」区块，按周六 / 周日分组列出课程长条，可点击查看详情。
  - 选课模式：「周末时段课程」区块，列出候选课程，点击进入选择（与逐格选课互通）。
  - 学习计划：「周末安排」区块，列出周末有课与已排计划。
- 副产物：学习计划空闲时段统计由 21 格降为 15 格。

### I.4 回归测试（`tools/smoke.js` §5）
模拟 `matchMedia` 返回窄屏后校验：渲染 5 天 × 3 时段、宽表格隐藏、视图内无「周六 / 周日」、
三种模式交互入口齐全、页面 `scrollWidth <= innerWidth`（无横向溢出）。
